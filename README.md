## 運用ルール

- 本リポジトリへの直接コミットはしない。原本はPrivateリポジトリにあり、公開前チェック(AI)→人間承認を経てエクスポートされる
- ルート直下に成果物を置かない(プロジェクト別に `projects/` 配下へ)
- 公開ファイルは先頭に出所メタデータ(project / source / published / checked)を付ける
- この索引表はエクスポート時に更新する

## 旧URLについて

旧構成のページ(ルート直下の automation.html 等)は `projects/multiproxy/docs/` へ移動し、リダイレクトを設定済み。
